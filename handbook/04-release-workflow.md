# IASevero Release Workflow

## Objetivo

Padronizar a publicação de versões da IASevero.

## Fluxo Oficial

Desenvolvimento
↓
Build
↓
Validação
↓
Testes
↓
Commit
↓
Tag
↓
Push
↓
Snapshot
↓
Arquivamento
↓
Documentação

## Critérios

- Build aprovado.
- Regressão aprovada.
- Git limpo.
- Tag publicada.
- Snapshot preservado.
- Documentação atualizada.
