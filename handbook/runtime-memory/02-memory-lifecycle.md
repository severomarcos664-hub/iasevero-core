# IASevero Runtime Memory Lifecycle

## Objetivo

Definir o ciclo de vida oficial da memória do runtime.

## Lifecycle

Request
↓
Context Acquisition
↓
Session Memory
↓
Operational Memory
↓
Planning
↓
Execution
↓
Evaluation
↓
Consolidation
↓
Long-Term Memory

## Regras

- Nenhuma memória é consolidada sem avaliação.
- Toda consolidação deve ser rastreável.
- A memória operacional é temporária.
- A memória consolidada é permanente até revisão.
