# IASevero Runtime Decision Architecture

## Objetivo

Definir como o runtime transforma planos em decisões executáveis.

## Fluxo

Goal
↓
Memory
↓
Planner
↓
Decision Engine
↓
Governance
↓
Execution

## Princípios

- Toda decisão deve ser explicável.
- Toda decisão deve ser auditável.
- A governança possui autoridade final.
- O runtime registra contexto, decisão e resultado.
