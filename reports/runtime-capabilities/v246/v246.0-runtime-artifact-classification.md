# v246.0 Runtime Artifact Classification

## Objetivo

Classificar todos os artefatos produzidos pela IASevero para definir sua localização permanente.

## Categorias

- Código-fonte
- Relatórios técnicos
- Snapshots
- Backups
- Builds temporários
- Logs
- Artefatos descartáveis

## Destino

Código
↓
GitHub

Relatórios
↓
Documentação

Snapshots
↓
Storage Externo

Builds
↓
Recriados quando necessário

Logs
↓
Rotação automática

## Preservação

- build
- testes
- commit
- tag
- push
