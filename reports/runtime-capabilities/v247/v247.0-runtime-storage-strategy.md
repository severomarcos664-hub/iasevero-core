# v247.0 Runtime Storage Strategy

## Objetivo

Definir a estratégia permanente de armazenamento da IASevero para reduzir o uso do Cloud Shell e facilitar a evolução da plataforma.

## Camadas

- Código-fonte
- Documentação
- Relatórios
- Snapshots
- Backups
- Builds
- Logs

## Estratégia

Código
↓
GitHub

Documentação
↓
Reports

Snapshots
↓
Storage Externo

Builds
↓
Recriados sob demanda

Logs
↓
Rotação automática

## Benefícios

- Shell sempre limpo
- Crescimento contínuo
- Menor consumo de armazenamento
- Facilidade de backup
- Base preparada para produção

## Preservação

- build
- testes
- commit
- tag
- push
