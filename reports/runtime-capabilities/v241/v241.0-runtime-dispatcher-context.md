# v241.0 Runtime Dispatcher Context

## Objetivo

Mapear todas as informações de contexto que poderão ser utilizadas pelo RuntimeToolDispatcher para selecionar automaticamente o executor mais adequado.

## Fontes de contexto

- prioridade
- estado operacional
- política de execução
- governança
- capacidade disponível
- tipo da etapa
