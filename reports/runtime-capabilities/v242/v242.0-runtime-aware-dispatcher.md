# v242.0 Runtime-Aware Dispatcher

## Objetivo

Evoluir o RuntimeToolDispatcher para considerar sinais operacionais do runtime antes de selecionar o executor.

## Sinais considerados

- operationalState
- priority
- executionAllowed
- governance
- provider
- fallback executor

## Critério

O Dispatcher deve manter fallback seguro para RuntimeExecutionPipeline quando nenhum sinal específico exigir outro executor.

## Preservação

- build
- testes
- commit
- tag
- push
