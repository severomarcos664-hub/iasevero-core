IASevero v188.0

Runtime Unified Intelligence Schema

PURPOSE
Define the canonical schema for the Runtime Unified Intelligence object.

SCHEMA FIELDS

- confidenceScore
- confidenceLevel
- riskLevel
- criticalityLevel
- governanceState
- executionAllowed
- executionPriority
- operationalState
- recommendation
- source
- timestamp

FIELD MEANING

confidenceScore:
Numerical trust score derived from existing confidence intelligence.

confidenceLevel:
Human-readable confidence classification.

riskLevel:
Risk signal derived from existing risk escalation intelligence.

criticalityLevel:
Execution criticality signal derived from existing criticality intelligence.

governanceState:
Governance and enforcement state derived from existing runtime governance.

executionAllowed:
Boolean decision indicating whether execution may proceed.

executionPriority:
Operational priority for execution handling.

operationalState:
Current runtime operational condition.

recommendation:
Unified operational recommendation generated by the Brain Kernel.

source:
Canonical source identifier for traceability.

timestamp:
Generation time for audit and telemetry.

ARCHITECTURAL RULE

This schema does not create new intelligence.
It standardizes the output format for intelligence already produced by the runtime.

SAFETY RULES

- No destructive refactor.
- No duplicated intelligence.
- No provider activation.
- No external model usage.
- Local-first remains mandatory.
- Build before preservation.
- Regression before preservation.

EXPECTED RESULT

A stable schema for future Runtime Unified Intelligence adapters and pipeline integration.
